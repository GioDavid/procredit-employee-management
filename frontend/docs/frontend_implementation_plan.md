Frontend implementation plan:

Login Form

Use Material UI to create a login form component
Connect to the backend API to authenticate users
Handle errors and display a success message after successful login
Bearer Token Authentication

Use the fetch API to send requests to the backend API with a Bearer token
Implement token refresh functionality to handle token expiration
Employee Table

Create a table component using Material UI
Fetch employee data from the backend API when the component mounts
Display employee data in the table
Implement search and filter functionality by department
New Employee Modal

Create a modal component using Material UI
Fetch department data from the backend API when the modal opens
Implement functionality to create a new employee
Display a success message after successful creation
Other

Use React 19 and TypeScript as the project requires
Implement routing using a library like React Router
Ensure all components are properly styled using Material UI
